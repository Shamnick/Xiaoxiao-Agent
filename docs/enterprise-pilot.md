# 企业试点范围与签收记录

当前阶段为试点准备。由愿意参与的组织和管理员确认以下内容后，在隔离环境用一项低敏项目开展验证。

| 启动项 | 由组织填写或确认 |
| --- | --- |
| 范围 | 项目、允许参与的设备、管理员与成员角色、试点时间 |
| 资料 | 可以发送给哪一服务的哪些字段、禁止外发的资料、保留期限 |
| 权限 | 允许的模型、个人 API 配置、工具与文件操作、谁能导出或删除 |
| 费用 | 可核验的账户上限、计费口径、能确认重提的人 |
| 运维 | 支持联系人、备份与恢复范围、升级失败的处理方式 |

| 管理员验收场景 | 核对方式 |
| --- | --- |
| 使用允许的模型交付一份文件 | 打开成品核对正文，检查服务请求和导出记录 |
| 成员从会话、历史、创作工作区切换到受限模型 | 每个入口核对受限资料发往该服务的请求数为 0 |
| 查询操作记录 | 核对操作者、时间、作品和动作，同时检查日志里是否出现密钥或未获准留存的正文 |
| 清除或恢复试点资料 | 按约定逐项核对会话、媒体、缓存及恢复副本 |
| 试用结束 | 记录通过项、复现步骤、支持投入、管理员意见与续用决定 |

每个结果记录构建版本、设备、角色、预期、实测、证据位置与复核人。低敏证据保存在双方约定的位置。当前签收组织数为 0。
