# 0.6.7 本机验收

2026 年 11 月 25 日，Apple Silicon，macOS 26.6.2。桌面测试均使用隔离的临时数据目录。除系统语音外，本记录中的模型和媒体生成使用本机回环 HTTP 服务。

| 验收项 | 操作与结果 |
| --- | --- |
| 选区与版本 | 分别改标题、正文和旁白，对照底图 SHA-256，检查撤销、分支与重启后的内容。模型预览请求仅含指定对象、选区及要求。请求进行中改选正文，原 HTTP 请求关闭。 |
| 旁白文件 | 从已保存的「周五来工作室看看。」打开语音草稿，用系统普通话音色合成。桌面播放器读取到正时长，导出后系统音频工具读出 WAV、单声道、22,050 Hz、1.83 秒。 |
| 视频恢复 | 服务接受任务后强制结束测试进程，再次启动只查询原任务，导出字节与服务返回值一致，累计提交 1 次。另测响应丢失后取消重提，提交总数保持原值。 |
| 旧版升级 | 分别用 0.6.3 和 0.6.6 创建会话、发送消息、置顶、保存模型与偏好、生成和保留未发送的图片草稿。各自退出并备份，0.6.7 逐项核对原目录与恢复副本，两条升级路径均通过，图片导出字节一致，额外模型请求均为 0。 |
| 大历史检索 | 1,000 个合成会话、20,000 条消息，历史文件 5,039,675 字节。从启动到首页可交互测得 616 毫秒（1 次）。10 次跨会话搜索均命中指定历史，16–88 毫秒，最后从结果跳到第 20 条消息。耗时包含桌面测试驱动。 |
| 发布验证 | 90 项单元测试及 11 组打包版桌面回归通过。应用和数据使用 Xiaoxiao 自己的标识和目录。系统安装版通过本地签名检查，升级前后核对了 3 份已有数据文件的摘要。 |

## 复验

运行 `npm run check`、`npm test`、`npm run pack`。在仓库根目录使用下面的命令测打包版。升级脚本会自行创建临时目录、备份及恢复副本，旧版路径通过 `XIAOXIAO_OLD_EXECUTABLE` 指定。

```sh
export XIAOXIAO_SMOKE_EXECUTABLE="$PWD/dist/mac-arm64/Xiaoxiao Agent.app/Contents/MacOS/Xiaoxiao Agent"
export XIAOXIAO_SMOKE_QA_DIR="$PWD/artifacts/qa-0.6.7"
npm run test:desktop
node scripts/history-scale-smoke.cjs
# 先将 XIAOXIAO_OLD_EXECUTABLE 指向保留的旧版可执行文件
node scripts/upgrade-recovery-smoke.cjs
```

## 支持范围

当前交付范围是 Apple Silicon Mac 本地试用。此次覆盖同一机器的升级与恢复。干净设备、其他平台、正式分发签名及公证均待验证。回环媒体测试覆盖协议和桌面流程。真实供应商的模型质量、视频账单、取消能力和实时语音打断需单独验收。[六期进度](innovation-roadmap.md)
