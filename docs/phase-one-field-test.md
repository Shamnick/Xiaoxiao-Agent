# 第一期试用 · 只改海报的一处

面向 5 位有改稿经验的试用者。观察一位创作者能否独立完成局部修改、确认影响范围、恢复旧版。当前记录为 0/5 人。发给试用者时只摘取分配到的任务卡。观察员说明和计分表留给主持人。

## 任务卡 A · 新品发布

你在准备一张新品发布海报。标题是「让灵感成形。」，旁白稿也用了这句话。请把标题改得更口语一些，保留彩色丝结底图和旁白原句。先看看修改前后的文案，再决定采用哪一句。

请指出如果稍后要让旁白也用新标题，你会怎么做。现在客户决定沿用原稿，请把作品恢复到开始时的样子。

## 任务卡 B · 体验邀请

你要发一张工作区体验邀请。标题是「开启你的创作之旅。」，旁白稿和标题相同。请把标题写短一些，保留工作区截图和旁白原句。比较新旧两句，采用你认为合适的版本。

请指出在哪里能让旁白跟随新标题。客户想先看看原版，请自行恢复海报，确认底图和旁白仍是最初的内容。

## 观察员如何组织两轮

惯用工具的两份起始材料都取自本地原型。每份准备一个可编辑标题、一张底图和一句独立旁白，旁白初始文字与标题相同。

| 简报 | 初始标题与旁白 | 底图 |
| --- | --- | --- |
| 新品发布 | 让灵感成形。 | [彩色丝结](../src/silk-knot.png) |
| 体验邀请 | 开启你的创作之旅。 | [桌面工作区](../src/proof-workspace.png) |

每人用 Xiaoxiao 和自己的惯用工具各做一份简报。每轮从原稿开始，只读任务卡，不演示入口。原型从丝结首页开始。惯用工具中预先放好同一张底图、可编辑的标题和独立的旁白文字，计时从展示任务卡开始，到参与者恢复原文为止。开始新参与者前，用全新原型会话或重启试用实例恢复示例。试用独立运行，无需接入模型。

| 参与者 | 第一轮 | 第二轮 |
| --- | --- | --- |
| P1 | Xiaoxiao A | 惯用工具 B |
| P2 | 惯用工具 A | Xiaoxiao B |
| P3 | Xiaoxiao B | 惯用工具 A |
| P4 | 惯用工具 B | Xiaoxiao A |
| P5 | Xiaoxiao A | 惯用工具 B |

每次要求参与者重复说明已经表达过的目标，记一次重复描述。每一次已生效的非目标修改记一次误改，包括旁白或底图的改动。记录给出提示的环节。中途放弃照样记入总人数，并记录停在哪一步。优先记录操作结果，录屏另征得同意。
