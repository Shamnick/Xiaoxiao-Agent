# Xiaoxiao Agent

Xiaoxiao Agent 是一款独立开发的多模型 AI 桌面工作空间，提供图片与视频视觉测试、独立生图、生视频、语音、代码编辑、流式对话、项目工具和 MCP。

## 直接使用

Apple Silicon Mac 可打开 `dist/mac-arm64/Xiaoxiao Agent.app`，也可将 DMG 中的应用拖到「应用程序」。本次本机试用构建采用 ad hoc 签名。对外分发需要 Developer ID 签名和公证。

1. 点击首页中央的丝结展开输入框，再点「连接模型」。点「听写」可使用 macOS 系统听写，确认文字后发送。旁边的扬声器可开启回复朗读。
2. 填写模型 ID、Base URL 和 API Key，保存后可测试连接、获取模型列表。
3. 回到对话，点输入框右下角的模型名，搜索后按 Enter 即可切换。点「更多模型」可读取当前连接的模型列表，也可以输入完整模型 ID 后选用。新会话的默认模型、外观、回复排版和发送键可在「设置 → 通用」调整。

首次使用默认深色。要切换到浅色或跟随系统，打开「设置 → 通用 → 窗口外观」。对话、创作中心、开发工作台、视觉实验室和改稿窗口会立即一起切换。已有窗口外观偏好会在升级后继续使用。「对话背景」可单独选择丝结光纹或纯净背景。
4. 点击「打开文件夹」选择项目目录。用「计划」检查项目和制定方案，用「任务」执行需要审批的改动。
   展开左上角导航并进入工作区后，「制定计划」会保留已有草稿并切换到计划模式。在「＋」上按方向键可选择附件与上下文，按 Esc 返回。
5. 「MCP 与运行」可增加外部工具，例如浏览器自动化。

### 从对话检测接口
在输入框点「＋ → 接口检测」，或发送「帮我检测这个模型接口」及地址。核对实际请求地址，需要鉴权时在密码框填写密钥，再点「检测并保存报告」。可以直接检测，无需先配置聊天模型。

应用向兼容网关发起一次模型列表读取。点击回复中的「打开 · 接口检测报告.html」即可查看检查时间、HTTP 状态、耗时和模型条数。鉴权失败或返回格式异常也会保存报告。检查范围仅涵盖模型列表，推理和余额需另外验证。再次检测时重新填写密钥。

### 查看对话用量

点击对话顶部的统计栏可以核对各项数字。输入和输出 token 取自模型接口，上报覆盖率按实际请求次数计算，包含重试和并行分析。缓存命中率只计入同时提供缓存读取量和输入量的请求。没有报告时显示 `—`，总量不完整时用 `≥` 标出已经记录的部分。

首段正文和总耗时由本机计时。只调用工具的步骤可能没有正文。右侧圆环标为「本地预算」，按最近主请求的文本长度和图像权重估算，分母是运行时当前使用的上下文整理阈值。

视觉测试可从侧栏底部的「图片与视频」打开。选择图片后可以直接发送给视觉模型，选择视频后应用会在本机均匀抽取六张带时间戳的画面。分析完成后使用「交给 Agent 继续」，会把同一组画面和初步结果交给当前 Agent。当前视频流程只处理画面，不读取音频。

「创作中心」提供独立的生图、生视频和语音模式。各模式使用设置中已保存的模型连接和对应模型 ID，可以更改接口路径，查看生成预览，并通过系统保存对话框导出文件。默认采用 OpenAI 风格的图片、视频和语音接口。不同网关的请求字段与任务状态协议可能不同，按服务文档调整 endpoint；未兼容的协议会显示服务错误。

API 用量按所配置提供商的账号计费。模型 ID 请使用你的账号实际可用的名称。不同模型的工具调用、上下文和兼容程度不同，不能保证每个网关都具有相同能力。

侧栏每条会话的「···」和右键菜单都可重命名、置顶、移动、导出、创建分支或删除。在一条回复下点「从此处分支」，会复制截至该回复的对话和模型设置。分支沿用项目目录，磁盘上的文件会共享。

## 比较同一次创作里的两张图

在「创作中心 → 生图」打开一条有至少两张成图的会话。点开任意缩略图，选择「版本对比」。有多轮结果时，默认将点开的图片与相邻轮次的一张作品并排显示，较早的在左侧。只有一轮时，可以比较这一轮的两张变体。

在左右下拉框按轮次和图片序号选图。各图下方是该轮提示词。「交换左右」可调换两张图的位置。点任意一侧的下载按钮可导出该侧原图。再次点「版本对比」回到单图，按 Esc 回到会话。查看、比较和导出都在本机完成。

## 只改海报标题

点击首页丝结，再点「试试局部改稿」。在「新品发布」或「体验邀请」中选择标题、正文或旁白。用「改成：」指定文案，或在标题上试试「口语一点」。选模型改写时，应用只发送所选段落、修改对象和要求。等待提案时可点「停止生成」，调整保留的修改要求后再次预览。只有点击「采纳修改」才会写入作品。比较后点「采纳修改」。如果旁白也要采用新标题，再点「同步这句到旁白」并采纳。各步都可撤销。作品按首页、项目或会话保存，重启后可以继续。会话分支继承分支点已有的作品版本。

切换标题、正文、旁白或简报时，各自的修改要求保存在本机。重启后回到同一份简报，可以接着输入。采纳提案会清空对应的要求，放弃提案可继续编辑要求。如果等待模型时作品已更新，界面会载入最新文案。点「预览修改」可基于新版再试一次。

点改稿窗口右上角的「导出海报」可预览当前已采纳版本，再点「保存 PNG」选择位置。预览和文件使用同一张 1440 像素宽的图像，较长文案会增加画布高度。

选中旁白，点「用这句制作语音」会打开一个新的语音草稿。Apple Silicon Mac 可选「Mac 系统语音 · 本机」，选择音色和语速，也可切换到已配置的语音服务。

**分段试听。** 在「创作中心 → 语音」中，每个非空行算一段。把光标放在第二段，点「生成第 2 段」，就会得到这一段的播放器。也可以拖选一句，点「生成选区」。点播放器下方的导出按钮可保存该片段。原稿保存在当前会话的输入框，可接着修改或试听其他段落。「生成全文」会合成整个输入框。本机语音每次最多接收 3,000 个字符，长稿可分段合成并导出 WAV。

**找回生成中的视频。** 打开创作历史，选中原视频，在该轮点「继续查询原视频」。应用用已保存的任务号向原服务查询。首次下载失败、查询断线或下载到空文件，都可以这样重试。若提示连接已更改，在设置中恢复原连接的模型和地址，再回到同一轮继续查询。

该轮会显示本次查询次数和下载状态。「停止」会结束本机等待，服务商可能仍在处理，之后可以再查。如果显示「提交结果未知」，请先到服务商核对任务和费用。「重新生成这一轮」会提交新的生成请求。

## 在生成途中修改 PDF

在普通对话输入「把周四的工作坊安排做成一页可下载的 PDF，列出预算 500 元」。模型生成时，在原输入框写「改到周五，并删去预算和金额」。点「立即改向」中止当前推理并采用新要求。正在执行的工具会先结束。想让本轮推理先完成时，点「发送补充」。在系统保存框选择位置后，从回复的「打开」查看 PDF 并核对日期和金额。这条流程需要所选模型支持工具调用。

## 开发运行

~~~bash
npm ci
npm start
~~~

需要 Node.js 22.16+。Electron 安装时需要下载运行时；若 GitHub 下载不可达，可在安装阶段指定你信任的镜像，例如：

~~~bash
ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ npm ci
~~~

运行时下载会根据 Electron npm 包内的 checksums.json 验证。npm 环境若阻止安装脚本，可手动运行 node node_modules/electron/install.js。

## 模型接入

| 服务 | 类型 | Base URL |
| --- | --- | --- |
| OpenAI 或兼容网关 | OpenAI Compatible | 使用服务方提供的 v1 根地址 |
| Claude | Anthropic | 默认 https://api.anthropic.com/v1 |
| DeepSeek、Gemini、通义千问 | OpenAI Compatible | 从服务预设填充，或填写你的部署地址 |
| Ollama | Ollama | 默认 http://127.0.0.1:11434/v1，无需 Key |

Base URL 不包含 chat/completions 或 messages。网络接口使用 HTTPS，本机回环地址可用 HTTP。遇到非流式网关时可关闭「启用流式输出」。已保存配置可获取模型列表，接口不支持列表时可手填模型 ID。

Key 由 Electron safeStorage 使用系统加密存储保护，不回传给对话界面。更换 API 地址时需要重新填写或清除原有 Key。对话历史和本地文件本身不加密；需要保护数据时请使用系统磁盘加密与账号访问控制。

## 在项目中搜索和编辑

1. 点击「打开文件夹」或按 `⌘O`。再次选择同一目录会打开已有项目。
2. 从工具栏选择「文件」或按 `⌘P` 搜索文件。按 `⇧⌘F` 搜索项目内容，选择结果可定位到对应行。
3. 在宽窗口点击「开发」或按 `⌘2` 进入三栏工作台。左侧切换文件、Git 和任务详情，中间编辑，右侧与 Agent 对话。文件树可用方向键展开和收起目录。点击文件树上的「新建文件」，可在现有目录下按相对路径创建文件。
4. 编辑后按 `⌘S` 保存或按 `⌘Z` 撤销。切换文件标签可继续编辑原草稿。若磁盘文件在编辑期间有变化，应用会阻止覆盖并保留编辑缓冲区。先复制需要保留的内容，再重新加载磁盘版本。
5. 输入框的「＋」可添加文本附件、引用项目文件或设置系统提示词。按 `@` 可直接选项目文件，也可用编辑器的「加入消息」或「引用选区」。每条消息最多四份，每份为不超过 64 KiB 的 UTF-8 文本。

### 用 AI 补写或改写

- 将光标放在要补写的位置，按 `⌥/` 或点「补写」。按 `Tab` 采纳并继续编辑，按 `Esc` 忽略。
- 选中代码后按 `⌘I`，输入要求并点击「生成建议」。例如，给函数补上空值处理。对照原选区与建议代码，再点「应用到编辑器」。保存仍由你控制。
- 编辑器底部的「自动补写」可为当前工作区开启随键入建议。本次应用退出后恢复关闭。启用后，短暂停顿时可能向当前模型发送光标附近的代码。请按你使用的模型服务和项目数据要求选择。补写和改写请求会计入该服务的 API 用量。
- 编辑器可在 JavaScript、TypeScript、Python、CSS、JSON 等已支持的格式里提示部分语法错误。点击状态栏的语法提示可定位问题。

## 审阅改动并提交

1. 进入「Git」选择已暂存或未暂存的文件，审阅逐行差异。可逐个暂存或取消暂存。应用会在更新索引前重新检查差异。
2. 在文件差异或「提交暂存改动」窗口点击「交给 Agent 审查」。确认计划模式输入区里的差异和提示词后，再发送给当前模型。单文件差异和整个暂存区的文本差异均可审查，上限为 64 KiB。
3. 打开仓库根目录时，可以点击「提交暂存改动」。核对暂存区快照并填写提交说明，再创建本地提交。仓库要求提交签名或运行 hooks 时，请使用终端提交。
4. Agent 提议写入时，打开「文件改动待审阅」，对照原文件、逐行差异与拟写版本。选择「应用改动」才写入。外部修改会使审批失效。
5. 从任务结果点开「文件改动」可回看该会话最近 40 次成功写入。选中对已有文件的写入记录，点「恢复原文」并检查差异，再确认恢复。恢复要求当前磁盘内容与记录中的写入版本一致，且编辑器没有该文件的草稿。每次恢复会添加一条新记录。

### 管理本地分支

打开 Git 仓库根目录，完成首次提交后，点 Git 面板中当前分支旁的下拉按钮。可选择已有分支，或从当前提交新建并切换。切换前需要保存编辑器草稿并处理暂存、未暂存和未跟踪改动。使用 Git 内容过滤器的目标文件可能需要在终端中切换。

## 在项目中运行与预览

用工具栏「项目终端」或按 Control 加反引号打开面板，再点「启动终端」。Shell 从当前项目目录启动。收起面板可保留会话，点击「结束终端」可停止。Agent 单独发起的命令会显示逐次确认，且命令使用当前系统账户的权限。

项目的开发服务器启动后，点击工具栏「项目预览」，输入终端显示的本机地址，如 `http://localhost:5173/`。预览在独立窗口打开，`⌘R` 可重新加载。支持 `localhost`、`127.0.0.1` 和 `::1`，页面资源与 WebSocket 请求限同一服务地址。

## 项目资料和交付稿

1. 打开项目的编辑面板，在「项目资料」点击「添加文本」。每个项目最多保存 12 份 UTF-8 文本，每份不超过 64 KiB。
2. 在该项目的对话或任务里，让模型参考指定文件。模型调用读取工具时，资料正文会发送给当前选择的服务。应用保存的是添加时的快照，更新原文件后可以移除旧资料再重新添加。
3. 在任务模式请 Agent 分别保存要交付的文档。点击回复下方的「查看交付物」后逐份打开。单份文档可直接从回复下方打开。
4. 预览支持排版、Markdown 源码和三种导出格式。Markdown 保留源文，PDF 适用于阅读和打印，Word 保留可编辑的标题、正文、清单和表格。对同一份交付物的改动会更新版本号，旧会话的单份交付稿仍可查看和导出。

## 在任务里复用项目约定和核对结果

在你选择的工作目录根部放置 `CLAUDE.md` 或 `AGENTS.md`，写下项目术语、格式约定或测试命令。两份文件都存在时会一起读取。交互式任务及规划模式每轮读取各文件开头最多 8 KiB 的 UTF-8 正文，随当轮请求发送到所选模型。只有根目录中的普通文件参与，项目约定里的导入和链接不会展开。普通聊天与定时任务沿用各自的项目资料设置。

同一批的本地搜索和读取最多三项并行。遇到写入、命令或需要确认的操作时，Agent 会先等前面的读取结束，再依次执行。运行中可以继续补充要求。

在「运行活动」里，「已写入并核对内容」表示保存后回读的字节与预期一致。「已写入，内容待核对」表示写入已发生，但回读未能确认。要检查网页交互或代码行为，可以在任务里指定要运行的测试，确认命令后查看结果。命令返回非零退出码时会标为「命令未成功」。

## 在多个任务间切换

在丝结首页或工作区按 `⌘K`（Windows / Linux 使用 `Ctrl+K`）打开会话导航。输入标题、项目名或消息正文。正文结果会显示匹配片段，打开后定位到最近一条命中消息。「待处理」集中显示需要回答、审阅、确认或手动继续的任务。使用方向键选择，Enter 打开，Esc 返回。

1. 把需要独立运行的工作分别发送到不同会话。侧栏「正在进行」显示各任务的状态。最多三个会话同时运行，相同或互相包含的工作目录会串行使用。
2. 任务运行时，在输入区写下新要求。「发送补充」在下一次模型请求采用它。「立即改向」中止当前推理，已经开始的工具在完成后接续。需要结束整项任务时，点「停止」。
3. 待回答和待确认会显示在侧栏。选择对应任务，在同一位置提交回答或检查操作的完整内容。拒绝会让工具返回拒绝结果。关闭 macOS 窗口后，应用仍运行时可以重新打开查看进度。
4. 切换会话会暂存未发送的文稿和附件。应用退出后，已发送内容、清单、交付物和中断记录可从会话找回，未发送内容需要重新输入。点击「继续任务」会把已保存的进度交给选定模型。

## 在同一任务中并行分析资料

在「任务」模式把目标和资料交给 Agent，例如「分别复核上线日期、共享范围和待办事项，再汇总成一份交付稿」。模型可把独立问题拆成两到三项，用当前模型同时分析。任务详情的「运行活动」显示已回收和未完成的数量。各项只接收主任务提供的目标与资料，没有工作目录或工具权限。点「停止」可取消整个批次，计划任务不会派发并行分析。

## 复用技能

在任务输入区打开「技能」。选择内置技能后点「用于此任务」，每个会话最多选三个技能。要导入自定义技能，选择包含 `name` 和 `description` YAML 头的 `SKILL.md`，在编辑区查看并保存，再选用它。

技能正文会随选用它的任务请求发给模型。导入只读取 Markdown，命令、附件脚本及目录中的其他文件不会一起导入。技能不会改变文件、命令和连接器的授权范围。

## 定时运行

1. 打开左下角「计划任务」，新建计划并写清每次运行的交付要求。选择模型、可选项目、每天或每周的时间。
2. 勾选「启用定时运行」后保存。也可以保留手动运行，随时点击「立即运行」。每次运行生成独立会话，可从最近记录打开。
3. 计划使用系统本地时间，应用进程需要保持运行。系统恢复后可在五分钟内补跑，超过窗口的运行记为错过。

计划任务可以生成应用内的文档。关联项目时，工具读取该项目的资料和工作目录。无项目时，工具可以读取公开 HTTPS 文本网页。计划会话采用只读工作区工具集，命令、写入和 MCP 调用均需在普通任务中单独执行。

## Agent 工具

| 工具 | 行为 |
| --- | --- |
| read_project_source | 读取当前项目内已保存的文本资料快照 |
| read_selected_document | 读取本次显式附加的 UTF-8 文本，最大 64 KiB |
| list_files | 列出所选目录的直接子项，最多 500 条 |
| read_file | 读取工作目录内文件，最多 64 KiB |
| search_workspace | 在工作区查找文件名或文本匹配 |
| edit_file | 对文件内的唯一匹配片段做精确替换，写入前审阅差异 |
| write_file | 写入工作目录内的 UTF-8 文本。原文件最多 64 KiB，拟写内容最多 12 KiB。每次写入都需审阅和确认 |
| run_command | 在所选目录执行命令；每次确认，最长 60 秒，输出最多 64 KiB |
| fetch_url | 读取公共 HTTPS 文本网页；不执行网页脚本，不自动跟随重定向 |
| ask_user | 在交互式任务中等待用户回答澄清问题 |
| update_task_plan | 更新会话中可见的任务清单 |
| delegate_analysis | 同时分析两到三份独立资料，每条普通任务请求最多使用一批。工作量计入所选模型的 API 用量 |
| save_task_draft | 按稳定的文档标识或标题创建和更新交付物 |
| MCP 工具 | 根据启用的服务发现工具；连接与每次调用均需确认 |

命令运行于当前用户权限下，工作目录不是操作系统沙箱。运行未知命令前查看确认窗口中的完整命令。文件工具会检查规范路径及符号链接边界，但不会限制你明确批准的命令或外部 MCP 服务访问范围。

Agent 最多执行 1–30 轮模型请求，可在设置里调整。默认 12 轮，单个任务 10 分钟超时，可随时停止。工具结果作为不可信数据传回模型。

## 浏览器与其他 MCP

在「MCP 与运行」保存服务器数组。默认关闭；设置 enabled 为 true 后，在下一次 Agent 请求时提示连接。

~~~json
[
  {
    "name": "Browser",
    "transport": "stdio",
    "command": "npx",
    "args": ["-y", "@playwright/mcp@latest"],
    "env": {},
    "enabled": false
  }
]
~~~

此例需要 Node.js/npx 和该服务要求的浏览器；生产环境建议把服务器版本固定为你验证过的版本。浏览器工具由外部服务提供，浏览器安装与第三方网页交互没有在本项目中做实站验证。

远程服务使用 transport: "http"、url、headers；本地进程使用 transport: "stdio"、command、args、env。env/header 值在磁盘上加密保存，设置界面可查看与编辑。配置界面包含密钥，分享截图或 JSON 时请自行移除。外部服务可能执行实际操作，每次工具调用都需要确认。

## 会话与数据

- 会话自动保存，支持重命名、删除和 Markdown 导出。
- 关闭窗口再打开可恢复历史；新建会话不会删除旧会话。
- 同一会话切换模型时，已完成的历史会发送给新选模型。需要隔离不同提供商的内容时先建新会话。
- 历史上下文最多取最近 40 条，并按约 12 万字符的软预算裁剪；失败回合不加入下一次模型上下文。
- 历史中的附件文字不永久附加；需要再次读取时重新附加文件。
- 独立数据目录：macOS 的 ~/Library/Application Support/Xiaoxiao Agent；不读取 Claude 或早期实验版目录。此目录保持稳定以便升级后继续使用自己的数据。
- settings.json、providers.json、conversations.json 使用原子替换写入，文件权限为 0600。
- `WorkspaceReviews` 保存批准写入前后的文本，文件权限为 0600，内容为明文。删除会话会同时删除其写入记录，项目文件仍留在磁盘。
- 桌面集成测试使用独立临时数据目录。

## 品牌与打包

在 src/brand.json 设置名称。修改 scripts/draw-icons.swift 后，在 macOS 运行 npm run icons，生成品牌图标、界面图标和安装包图标。

npm run icons

## 正式分发 Mac 安装包

在装有项目依赖的 Apple Silicon Mac 上，将有效的 Developer ID Application 证书和对应私钥保存在钥匙串中。用 `xcrun notarytool store-credentials` 交互式保存公证凭据，将配置名称赋给环境变量 `APPLE_KEYCHAIN_PROFILE`。使用自定义钥匙串时，通过 `APPLE_KEYCHAIN` 指定公证凭据所在的位置。多个发布证书共存时，可用 `XIAOXIAO_SIGN_SHA1` 指定证书指纹。

1. 运行 `npm run release:mac -- --check`。命令在本机检查签名身份、工具和配置名称。凭据的有效性由 Apple 在公证请求中验证。
2. 运行 `npm run release:mac`。脚本构建 arm64 应用和签名 DMG，向 Apple 提交 DMG，并等待公证结果。通过后附加票据并验证系统对磁盘映像的评估结果。
3. 脚本只读挂载最终 DMG，校验其中的应用签名和系统启动评估，用临时数据目录运行创作中心与局部改稿回归。成功后终端给出分发文件路径。请使用该路径下的 DMG 做干净设备首次安装和旧版升级验收。

## 验证

在装有本项目依赖的 Mac 上，运行 `npm run test:installed:mac` 可验收「应用程序」中的 Xiaoxiao Agent。请使用与安装版同版本的源码。测试会创建临时用户目录，核对运行中的版本、可执行文件和数据路径，操作首页、打开改稿窗口并生成语音，最后将导出的 WAV 片段与播放器中的音频逐字节比较。命令返回成功才算通过本项验收。

~~~bash
npm run check
npm test
npm run test:desktop
~~~

单元测试覆盖模型协议、代码建议格式、工具范围、保存和恢复冲突所依赖的版本检查、Git 暂存快照与分支、技能文本和计划时间。桌面测试使用本地模拟服务，验证文件树、补写、计划、审批和恢复、单文件及多文件审查、本地提交、终端和网页预览。回归还包含会话恢复、文档导出和定时运行。真实模型的工具能力需要按服务分别验证。
